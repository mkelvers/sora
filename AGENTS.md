# Agent instructions

This project uses Ultracite (oxlint and oxfmt). Run `bunx ultracite fix` before committing and `bunx ultracite check` to see what is left. Fix every diagnostic in the code itself: no suppression comments, no justification markers and no type assertions, even behind a `SAFETY:` comment. Use checked assignments, narrowing or schema parsing instead; const assertions are fine. The one exception is a negative type test in a `*.test.ts` file, which may use `@ts-expect-error` with a reason, on its own, where TypeScript confirms the next statement really errors. `bun run lint` first runs a pass that fails on any disable directive, so a file can't switch off the suppression rule itself; keep that pass in `lint` and `lint:fix`.

Every worktree shares one local dev database, and a careless migration breaks it for all of them. Load the `database-migrations` skill in `.agents/skills/` after pulling or switching worktrees, when changing the schema, or when `db:migrate` refuses to run.
